# Web Performance Auditor v0.2.0

Минорный релиз Chrome-расширения для локального аудита Core Web Vitals: LCP,
CLS, INP, FCP и TTFB с атрибуцией к DOM и диагностикой причин. Добавлены импорт
ранее экспортированных JSON-отчётов и история сессий.

## Установка

1. Скачайте `web-performance-auditor-0.2.0.zip` из ассетов релиза.
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.
5. Откройте обычную http/https страницу и нажмите иконку расширения — Side
   Panel откроется справа.

Требования: Chrome/Chromium 116+. Проверьте SHA-256 по файлу
`web-performance-auditor-0.2.0.zip.sha256`.

## Что добавлено

- **Импорт JSON.** На вкладке «Данные» загрузите файл, созданный кнопкой
  «Экспорт JSON». Панель покажет URL, дату, браузер, число метрик/событий/
  экспериментов и предупреждения, затем добавит отчёт в историю. Импорт
  создаёт независимую сессию с новыми id, переназначает ссылки и никогда не
  перезаписывает существующие записи. Активная сессия импортируется как
  прерванная, running-эксперимент — как незавершённый; DNR-правила не
  восстанавливаются.
- **История сессий.** Список последних сессий с датой, URL, статусом,
  количеством метрик/событий/экспериментов и пометкой «Импорт». Сессию можно
  открыть (когда наблюдение остановлено) или удалить с подтверждением.
- **Обнаружение молчаливого отказа `buffered`.** Коллектор сравнивает
  исторические записи `performance.getEntriesByType()` с тем, что доставил
  буферизованный наблюдатель. Если записи были, но не пришли, добавляется
  событие `collector-limitation` с причиной `buffered-unavailable` и пометкой
  «возможно».
- **Автотест permission-denied.** Ветка отказа инжекции вынесена в `startAudit`
  и покрыта unit-тестами: сессия завершается статусом `error`, панель
  показывает `permission-denied`.

## Что внутри

- Сбор пяти Core Web Vitals и атрибуция к элементам страницы.
- График сессии, события, детали метрик, копирование диагностики.
- SPA- и документные сегменты навигации.
- Эксперименты с временной блокировкой доменов (DNR) и сравнением метрик.
- Экспорт JSON и Markdown без query-параметров URL; импорт JSON.
- Статус полноты данных с причинами.
- Подсветка целей LCP/CLS/INP и обнаружение удаления/замены/перемещения.
- Локальное хранение, без сетевых отправок.

- `npm run verify`: типы, lint, 171 unit-тест, production-сборка.
- E2E: 47/47 PASS, включая импорт, отказ от повторного импорта, список
  истории, выбор и удаление импортированной сессии.
- Accessibility: axe-core 17 состояний + keyboard-путь по всем четырём
  вкладкам, 17/17, 0 serious/critical.
- `npm audit --omit=dev`: 0 уязвимостей.
- Zip воспроизводим из чистого checkout и совпадает с CI-артефактом,
  SHA-256 не зависит от часового пояса сборки.
- `npm run verify:release`: zip распаковывается и загружается в Chrome.

## Известные ограничения

- Только Chrome/Chromium; Firefox-адаптера нет.
- Автоматической миграции записей между версиями схемы нет: несовместимые
  записи игнорируются и удаляются retention-очисткой.
- Импортированная сессия доступна только для чтения: повторно запустить
  наблюдение или восстановить DNR-правила из неё нельзя.
- Если браузер молча принимает `buffered: true`, но не отдаёт исторические
  записи, ограничение фиксируется консервативно и с пометкой «возможно»; при
  отсутствии исторических записей событие не создаётся.
- Permission-denied проверяется unit-тестом, а не отзывом host-permission в
  живом Chrome.
