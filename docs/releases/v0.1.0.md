# Web Performance Auditor v0.1.0

Первый публичный релиз Chrome-расширения для локального аудита Core Web
Vitals: LCP, CLS, INP, FCP и TTFB с атрибуцией к DOM и диагностикой причин.

## Установка

1. Скачайте `web-performance-auditor-0.1.0.zip` из ассетов релиза.
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.
5. Откройте обычную http/https страницу и нажмите иконку расширения — Side
   Panel откроется справа.

Требования: Chrome/Chromium 116+. Проверьте SHA-256 по файлу
`web-performance-auditor-0.1.0.zip.sha256`.

## Что внутри

- Сбор пяти Core Web Vitals и атрибуция к элементам страницы.
- График сессии, события, детали метрик, копирование диагностики.
- SPA- и документные сегменты навигации.
- Эксперименты с временной блокировкой доменов (DNR) и сравнением метрик.
- Экспорт JSON и Markdown без query-параметров URL.
- Статус полноты данных с причинами.
- Подсветка целей LCP/CLS/INP и обнаружение удаления/замены/перемещения.
- Локальное хранение, без сетевых отправок.

## Проверки релиза

- `npm run verify`: типы, lint, 124 unit-теста, production-сборка.
- E2E: 41/41 PASS.
- Accessibility: axe-core 10 состояний + keyboard-путь по всем четырём
  вкладкам, 15/15, 0 serious/critical.
- Performance: TaskDuration +4,9…5,8 % (8–10 мс), heap +0,26…0,35 МБ —
  в принятом бюджете.
- `npm audit --omit=dev`: 0 уязвимостей.
- Zip воспроизводим из чистого checkout, SHA-256 совпадает.
- `npm run verify:release`: zip распаковывается и загружается в Chrome.

## Известные ограничения

- Только Chrome/Chromium; Firefox-адаптера нет.
- Импорт ранее экспортированного JSON не реализован.
- Автоматической миграции IndexedDB v1 → v2 нет: несовместимые записи
  игнорируются и удаляются retention-очисткой.
- Ограничение `buffered`-наблюдателей фиксируется только при явной ошибке API.
- Permission-denied сценарий проверен кодом, но не автоматизирован.
