# Web Performance Auditor v0.3.0

Минорный релиз расширения для локального аудита Core Web Vitals: LCP, CLS, INP,
FCP и TTFB с атрибуцией к DOM и диагностикой причин. Добавлены Firefox-сборка,
миграции сохранённых записей между версиями схемы и усиленный CI.

## Установка

### Chrome / Chromium

1. Скачайте `web-performance-auditor-0.3.0.zip` из ассетов релиза.
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.
5. Откройте обычную http/https страницу и нажмите иконку расширения — Side
   Panel откроется справа.

Требования: Chrome/Chromium 116+. Проверьте SHA-256 по файлу
`web-performance-auditor-0.3.0.zip.sha256`.

### Firefox

В релизе нет подписанного Firefox-пакета: Firefox устанавливает неподписанные
расширения только как временные. Соберите пакет из исходников:

```bash
npm install
npm run build:firefox
```

Затем откройте `about:debugging#/runtime/this-firefox` → «Загрузить временное
дополнение» → выберите `dist-firefox/manifest.json`. Для постоянной установки
пакет нужно подписать в Mozilla Add-ons; идентификатор
`web-performance-auditor@wwsxdc.github.io` уже задан в манифесте. Требования:
Firefox 142+. Подробности — [`docs/firefox.md`](../firefox.md).

## Что добавлено

- **Firefox-адаптер.** Общий слой `src/browser/api.ts` выбирает `browser`
  (Firefox) или `chrome` (Chromium), поэтому один и тот же код работает в обоих
  браузерах. Отдельный `manifest.firefox.json` использует event page
  (`background.scripts` + `type: "module"`) и `sidebar_action` вместо Side
  Panel; кнопка на панели инструментов открывает/закрывает боковую панель, а
  popup остаётся fallback. Сборка — `npm run build:firefox` → `dist-firefox/`.
- **Миграции схемы IndexedDB.** Реестр `src/background/migrations.ts` переводит
  поддерживаемые старые записи (`schemaVersion` 1) в текущую схему при чтении и
  записывает результат обратно. Восстанавливается документный сегмент из
  `navigationId`, нормализуются browser, массивы и статусы. Неизвестные и
  будущие версии по-прежнему не читаются и удаляются retention-очисткой.
- **Надёжность восстановления.** Повреждённый указатель активной сессии
  удаляется при `restore()`. Добавлены тесты на закрытую вкладку, ротацию
  `documentToken`, SPA-переход во время восстановления и сессию под старой
  схемой.
- **CI.** Performance-бюджет коллектора вынесен в отдельный job `perf`, релиз
  зависит от зелёных `e2e` и `perf`. Firefox-пакет собирается и публикуется
  как artifact `web-performance-auditor-firefox`.
- **Доступность.** axe-гейт расширен до 23 состояний: inline-подтверждение
  удаления, ошибки импорта и настроек, сохранённые настройки, журнал
  диагностики и сравнение эксперимента.

## Что внутри

- Сбор пяти Core Web Vitals и атрибуция к элементам страницы.
- График сессии, события, детали метрик, копирование диагностики.
- SPA- и документные сегменты навигации.
- Эксперименты с временной блокировкой доменов (DNR) и сравнением метрик.
- Экспорт JSON и Markdown без query-параметров URL; импорт JSON и история
  сессий.
- Статус полноты данных с причинами.
- Подсветка целей LCP/CLS/INP и обнаружение удаления/замены/перемещения.
- Локальное хранение, без сетевых отправок.

## Проверки релиза

- `npm run verify`: типы, lint, 209 unit-тестов, production-сборка.
- E2E: 47/47 PASS на финальном `dist/`.
- Accessibility: axe-core 23 состояния + keyboard-путь по всем четырём
  вкладкам, 23/23, 0 serious/critical.
- Performance: `TaskDuration` +8,5 % (+14,1 мс), JS-heap +0,31 МБ — в бюджете
  (абсолютный порог 25 мс, heap 1,5 МБ).
- `npm audit --omit=dev`: 0 уязвимостей.
- `npm run verify:release`: zip распаковывается и загружается в Chrome.
- Firefox: `web-ext lint` — 0 ошибок (2 предупреждения `innerHTML` во
  стороннем React-бандле); `dist-firefox/` установлен как временное дополнение
  в Firefox 159.0.1.
- Zip воспроизводим из чистого checkout; SHA-256 не зависит от часового пояса
  сборки.

## Известные ограничения

- Firefox-пакет не покрыт автоматическим E2E: `e2e/*` использует Puppeteer и
  Chrome. Автоматически проверены сборка, структура пакета, `web-ext lint` и
  установка временного дополнения; полный ручной smoke-тест (старт аудита,
  метрики, оверлей, эксперимент, экспорт) остаётся шагом перед публикацией в
  Mozilla Add-ons.
- Неподписанный `dist-firefox/` загружается только как временное дополнение.
- Миграции поддерживают только известные старые версии (сейчас v1 → v2).
  Записи с неизвестной или будущей `schemaVersion` не читаются и удаляются при
  retention-очистке.
- Импорт остаётся аддитивным: существующие записи никогда не перезаписываются,
  импортированная сессия доступна только для чтения.
- Поведение `declarativeNetRequest` и кэша в Firefox может отличаться от
  Chrome, поэтому сравнение эксперимента остаётся измерением, а не гарантией.
- p75-агрегация по нескольким сессиям не реализована (вне scope релиза).
