Privacy policy

Last updated: 11 November 2026

Short version: Web Performance Auditor does not collect, transmit, sell, or share personal data. All measurements stay in your browser profile.

1. Who we are

Web Performance Auditor is an open-source browser extension maintained at github.com/wwsxdc/web-performance-auditor. For privacy questions, open an issue in that repository.

2. What the extension stores

The extension works locally. It stores the following data in IndexedDB and storage.local inside your browser profile:

  • Core Web Vitals values (LCP, CLS, INP, FCP, TTFB) and measurement timestamps.
  • The page URL reduced to origin + pathname; query strings and hashes are removed.
  • DOM attribution data: element selectors, short text snippets, and metric details.
  • Performance events such as Long Tasks and SPA navigations.
  • Experiment configuration and session comparison data.
  • Extension settings and a small diagnostic log (no page content or page URL).

3. What the extension does not do

  • It does not send data to any server.
  • It does not use analytics, telemetry, advertising, or crash reporting.
  • It does not use accounts or cloud sync.
  • It does not load remote code, remote fonts, or remote scripts.
  • It does not read pages outside the http/https URLs you audit.

4. Permissions

storage keeps settings and the active session pointer. scripting and webNavigation run the local collector and split a session into page and SPA segments. declarativeNetRequest is used only for session-scoped blocking rules during an experiment. Host permissions for http://*/* and https://*/* are needed to measure pages early. The extension does not request the tabs permission.

5. Retention and deletion

History is limited to 50 sessions, 500 events and 1000 metrics per session. Sessions expire after 30 days by default; you can change the retention period in Data → Settings. You can delete all stored data at any time from Data → Clear history, or by removing the extension.

6. Third parties

There are no third-party services, data processors, or trackers. The extension is distributed through Mozilla Add-ons; Mozilla's own privacy practices are described on mozilla.org.

7. Children

The extension is a developer tool and is not directed at children. It does not knowingly collect data from anyone.

8. Changes

If this policy changes, the updated version will be published at this URL with a new date. Material changes will be noted in the extension release notes.

Политика конфиденциальности

Обновлено: 11 ноября 2026 г.

Коротко: Web Performance Auditor не собирает, не передаёт, не продаёт и не раскрывает персональные данные. Все измерения остаются в профиле вашего браузера.

1. Кто мы

Web Performance Auditor — расширение с открытым исходным кодом: github.com/wwsxdc/web-performance-auditor. Вопросы о приватности можно задать в Issues этого репозитория.

2. Какие данные хранит расширение

Расширение работает локально и хранит данные в IndexedDB и storage.local внутри профиля браузера:

  • значения Core Web Vitals (LCP, CLS, INP, FCP, TTFB) и время измерений;
  • URL страницы в виде origin + pathname — query и hash удаляются;
  • данные привязки к DOM: селекторы элементов, короткие текстовые фрагменты и детали метрик;
  • события производительности: Long Tasks и SPA-навигации;
  • конфигурацию экспериментов и данные сравнения сессий;
  • настройки расширения и небольшой журнал диагностики без содержимого страницы и её URL.

3. Чего расширение не делает

  • Не отправляет данные на серверы.
  • Не использует аналитику, телеметрию, рекламу и отчёты о сбоях.
  • Не требует аккаунта и не синхронизирует данные с облаком.
  • Не загружает удалённый код, шрифты и скрипты.
  • Не читает страницы за пределами http/https-адресов, которые вы аудируете.

4. Разрешения

storage хранит настройки и указатель активной сессии. scripting и webNavigation запускают локальный коллектор и делят сессию на документные и SPA-сегменты. declarativeNetRequest используется только для временных правил блокировки в эксперименте. Host permissions для http://*/* и https://*/* нужны для раннего измерения страниц. Разрешение tabs не запрашивается.

5. Срок хранения и удаление

История ограничена 50 сессиями, 500 событиями и 1000 метриками на сессию. По умолчанию сессии хранятся 30 дней; срок можно изменить в разделе «Данные» → «Настройки». Удалить все данные можно в любой момент через «Данные» → «Очистить историю» или удалив расширение.

6. Третьи стороны

Нет сторонних сервисов, обработчиков данных и трекеров. Расширение распространяется через Mozilla Add-ons; практики Mozilla описаны на mozilla.org.

7. Дети

Расширение является инструментом разработчика и не адресовано детям. Оно не собирает данные сознательно.

8. Изменения

Обновлённая политика будет опубликована по этому адресу с новой датой. Существенные изменения будут отмечены в примечаниях к релизу.
