## [0.1.0] — 2026-11-04

Первый публичный релиз Chrome-расширения для локального аудита Core Web
Vitals.

### Добавлено

- Сбор LCP, CLS, INP, FCP и TTFB через `web-vitals` с атрибуцией к DOM-узлам
  и диагностическими событиями (long tasks, сдвиги, взаимодействия).
- Side Panel: обзор метрик, график сессии, события, эксперименты, данные,
  настройки, журнал диагностики и очистка истории.
- Popup-fallback для окружений без Side Panel API.
- Документные и SPA-сегменты навигации; load-метрики привязаны к документу,
  CLS/INP — к активному сегменту.
- Эксперименты с временной блокировкой доменов через session DNR-правила,
  сравнением метрик и гарантированной очисткой правил.
- Экспорт JSON (версионированный, с проверкой схемы) и Markdown для
  GitHub/GitLab Issues.
- Статус полноты сессии: «Полная» / «Частичная» / «Ограниченная» с причинами
  и временем начала наблюдения; тот же блок в JSON/Markdown.
- Обнаружение удаления, замены и перемещения подсвеченного элемента (FR-14)
  по структурному якорю.
- Пакетная запись диагностических событий: одна транзакция IndexedDB на пакет,
  принудительный flush на stop/navigation/reset/лимит/ошибку.
- Accessibility-гейт (`npm run test:a11y`): axe-core по 10 состояниям,
  keyboard-проверки по всем вкладкам (15 проверок), 0 serious/critical.
- Performance-бенчмарк (`npm run bench:collector`) и decision record по
  накладным расходам.
- Воспроизводимый release-артефакт (`npm run package`) с SHA-256 и проверкой
  установки (`npm run verify:release`).

### Изменено

- URL в отчётах и событиях очищаются от query/hash (`sanitizeUrl`).
- Хранение ограничено: 50 сессий, 500 событий и 1000 метрик на сессию,
  retention 30 дней.
- Несовместимые `schemaVersion` не читаются и удаляются при retention-очистке;
  политика описана в `docs/storage.md`.

### Исправлено

- Повторные callback одной метрики больше не считаются независимыми
  измерениями; в экспорт попадает одна актуальная запись на метрику/сегмент.
- Восстановление сессии после перезапуска service worker с grace-таймером
  навигации.
- Fallback CLS/INP ограничен текущим документом; поздние сообщения старого
  документа отбрасываются по `documentToken`.
- Проверка отправителя и полномочий для остановки сессии, подсветки и
  экспериментов.
- Focus-visible, контраст, landmarks и accessible names в Side Panel/popup.
- Вкладки Side Panel получили полный ARIA-паттерн: roving `tabindex`,
  `aria-controls`/`tabpanel` и переключение стрелками, `Home`/`End`.

### Безопасность

- Нет сетевых отправок и удалённого кода; все данные остаются в профиле.
- Content script проверяет источник, origin, схему и размер page-сообщений.
- DNR-правила ограничены вкладкой и доменами, удаляются при завершении,
  отмене, очистке и восстановлении.
- `npm audit --omit=dev`: 0 уязвимостей.
- Подробности — `SECURITY.md` и `docs/security/privacy-review.md`.

### Известные ограничения

- Только Chrome/Chromium; Firefox-адаптера и отдельного манифеста нет.
- Импорта ранее экспортированного JSON нет.
- Автоматической миграции IndexedDB v1 → v2 нет; несовместимые записи
  удаляются (осознанно для первого релиза).
- Если браузер молча принимает `buffered: true`, но не отдаёт исторические
  записи, это неотличимо от пустой истории; ограничение фиксируется только
  при явной ошибке API.
- Permission-denied сценарий проверен кодом, но не автоматизирован.
